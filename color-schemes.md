## **How to Apply a Color Scheme:**

1. Open `src/app/globals.css`
2. Find the `:root` section (lines 3-14)
3. Replace the color values with your chosen scheme
4. Save the file - changes will apply immediately!

---

## **Custom Color Scheme:**

Want to create your own? Use this template:

```css
--primary: #YOUR_COLOR;           /* Main brand color */
--primary-light: #LIGHTER_VERSION; /* 20% lighter */
--primary-dark: #DARKER_VERSION;   /* 20% darker */

--background: #DARK_COLOR;         /* Main background */
--background-secondary: #SLIGHTLY_LIGHTER;
--background-accent: #EVEN_LIGHTER;
```

**Pro Tips:**
- Keep background colors dark (10-15% brightness)
- Ensure good contrast between primary and background
- Test readability with white text on primary color
- Use online tools like coolors.co or paletton.com
